# Stock_LineNotify
## 動機
在通膨時代，有效投資成為資產增值的核心。一般投資者常面臨以下痛點：
1. **資訊獲取不即時**：無法即時盯盤，容易錯過進場點。
2. **情緒化決策**：在市場波動時容易因恐慌或貪婪做出錯誤判斷。

## 核心技術與實作：
* **數據來源**：串接 永豐金 (Shioaji) API，獲取即時與歷史股票數據，處理非結構化金融資訊。
* **技術指標計算**：運用 Python 邏輯分析 EMA (指數移動平均線)、MACD 與其信號線（Signal Line），判斷多空趨勢及交叉點。
* **風險管理邏輯**：實作動態追蹤算法，計算當日跌幅、連續下跌天數及累積下跌百分比，作為反向投資或分批進場的參考依據。
* **自動化通知**：整合 LINE API 實現自動化推播，將複雜的數據處理結果轉化為簡潔的「交易建議」。

## 專案成就：
* **全天候監控**：系統自動抓取即時股票數據，取代人工盯盤，確保在關鍵轉折點（如 MACD 交叉或跌幅超過預設門檻）第一時間獲取通知。
* **決策客觀化**：透過數據量化取代主觀判斷，提升交易的一致性與紀律。
